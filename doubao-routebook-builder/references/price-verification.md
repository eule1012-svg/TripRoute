# 价格核实与货币换算（price-verification）

方案中所有价格必须**核实**，禁止估算值充当真实价格；标注来源与汇率基准日。

## 一、核实范围

- 机票（含直飞/中转、促销价）、火车/大巴票价
- 酒店/青旅真实价格（按规划日期查询，标注评分与预订渠道）
- 体验活动价格（Klook/KKday/官网）
- 签证费、保险
- 商务考察相关：公司注册规费、代理费、资本实缴最低标准、支付通道费率（MDR/月费/结算周期）

## 二、核实方式

1. 搜索官方/权威来源（航司官网、OTA、酒店官网、Klook、政府/央行/使馆页面、行业白皮书）
2. **区分核实状态**并写进产物：`已核实`（官方页面/权威来源）/ `待现场确认`（来源口径有差异，需当面书面确认）/ `未核实`（第三方综述区间，官方未挂牌）
3. 商务落地类数据（注册费、实缴、费率）：以官方条文+律所/代理综述交叉验证；口径冲突时标注"差异+需书面复核"
4. 价格按**规划的具体日期**查询（淡旺季差异大），并在交付说明注明查询日期

## 三、货币换算（硬性）

- 所有金额**以当地货币为主**，后面括号标人民币等值：`213,000–349,000₫/人/晚 ≈ ¥55–90`
- 换算用当日汇率，标注基准日与来源：`（2026-09-16 新浪财经：1 CNY≈3,876₫，1 CNY≈3,321₭，1 USD≈¥6.71）`
- 多国路线逐国标注本国货币符号（₫=越南盾、₭=老挝基普、₮=蒙古图格里克、$=美元…）
- 预算总表：分项用原始货币 + 人民币折算，合计后核对人均红线
- 使用 calculator 工具做换算，禁止口算

## 四、预算表规范（06 板块）

- 预算条：名称 / 进度条 / `¥区间 ｜ 占比%` 三栏（grid），**禁悬浮 min/max 小标签**（已踩重叠坑）
- 进度条百分比 = 该项区间中值 ÷ 总预算中值，用 calculator 计算
- 人均红线醒目展示（如 `人均 ≤¥10,000`）+ 严控后区间
- 省钱 tips 4–5 条（直飞省时、淡季价格、门票减法、提前抢促销、混合住宿等）

## 五、来源可追溯

- 每个关键价格/费率后面挂来源（官方域名即可，如 vnpay.vn / bcel.com.la / hostelworld.com），交付说明列出完整来源清单与基准日
- 无法核实的：写"待询价/未挂牌"，不编数字
