# 需求采集清单（intake-questions）

生成任何路书方案前，**必须**与用户逐项确认。先问必问项，再根据回答追问相关扩展项。一次最多问 4 个问题，分轮完成；用户已回答过的维度不得重复询问。确认完毕后，把结果固化为任务画像表，后续所有决策（天数分配、住宿、交通、预算、板块取舍）都以画像为准。

## 一、必问核心项（12 项，缺一不可）

1. **出行国家/地区**：单国还是多国？如果是多国，是否确定入境顺序（先到哪国、后到哪国）？是否有跨境交通连接（航班/铁路/大巴）？
2. **出行月份与具体出发日期**：几月出发？有没有固定日期（如 11 月 7 日）？——决定天气、旺季/淡季、节日、票价档位。
3. **出行人数与构成**：几人？双人/家庭/团队？是否包含老人、儿童、行动不便者？（影响节奏、住宿房型、活动选择）
4. **行程天数**：总天数区间（如 10–15 天）。是否需要在方案中预留 1–3 天自由安排时间？
5. **预算范围**：人均红线多少？总预算多少？用哪个币种衡量（人民币/美元/欧元）？预算含机票签证吗？（决定住宿档次、航班直飞/中转、体验活动取舍）
6. **住宿条件**：偏好档次？是否接受青年旅舍、混住宿舍？是否愿意"70% 高性价比 + 30% 特色酒店"的混合策略？位置要求（市中心/海边/商务区）？
7. **交通偏好**：是否偏好体验特色交通（跨境大巴、景观铁路、卧铺夜车、渡轮）？长途是否接受飞机？有没有明确想坐/不想坐的交通工具（如不想坐长途大巴）？需要包车/自驾吗？
8. **是否需要导游/讲解**：全程导游、景点讲解、还是自由行+当地参团？语言需求（是否需要中文/英文导游）？
9. **是否需要当地特色活动**：如烹饪课、一日游、节庆体验、水上运动、徒步、夜市逛吃等？更偏向网红打卡还是深度小众？
10. **饮食需求**：对当地特色美食的兴趣度？有无忌口（清真/素食/海鲜过敏等）？是否希望安排特色餐饮（如料理课、市场美食之旅）？
11. **文化需求**：对古城、寺庙、博物馆、传统村落、非遗手工艺的偏好？是否想体验当地节庆/宗教仪式？
12. **商务考察需求**（如用户说"无考察"，必须再追问确认一次，避免遗漏）：
    - 考察哪个行业/领域？（电子支付、电商、二手车进出口、供应链、制造业、新能源、旅游接待……）
    - 想了解哪些具体方面？（市场规模、竞争格局、政策法规、税费成本、资质门槛、落地路径、渠道资源……）
    - 最终想达成什么结果？（拓展业务、找合作伙伴、投资落地、了解政策可行性、开户/注册公司、建立供应链……）
    - 需要在当地做什么具体动作？（拜访企业、对接代理商、考察市场、注册公司、银行开户、参加展会、拜访政府部门……）

## 二、补充因素（用户点名要求列举的"其他重要因素"，视回答情况追问）

13. **签证与证件**：两国/多国签证办理计划？是否需要代办信息、落地签/电子签政策？
14. **出发城市**：从哪个城市出发？（决定直飞航班与第一段交通；默认按用户所在地）
15. **航班偏好**：直飞优先还是接受中转？对航司/时间（红眼/白天）有偏好吗？
16. **设备携带**：是否携带无人机、运动相机、插线板等？是否需要当地电源插头、禁飞区信息？
17. **宗教与文化禁忌**：目的地有宗教礼仪（如进庙要求）或文化禁忌时，是否需要在方案中标注提醒？
18. **行程节奏**：偏好紧凑（一天多景点）还是松弛（每天 1–2 个核心点）？能接受夜车/早班车吗？
19. **特殊安排**：是否有纪念日、生日、求婚、蜜月等需要在行程中安排的节点？
20. **健康与体力**：有无高原/晕车/体力限制？需要安排海拔适应、避免剧烈活动吗？
21. **保险**：是否需要境外旅行保险推荐（含医疗、航班延误、行李）？
22. **交付形态**：需要 HTML 路书即可，还是同时要报价表（Excel/飞书表，按模板 USD/当地货币计价）、飞书文档备份、打包 zip？
23. **预订链接**：票务/酒店/体验是否需要给出可点击的真实预订入口（官方/Klook/Booking 等）？
24. **图片来源要求**：是否需要全量真实图片（景点、酒店外观+房间、交通、体验），并禁第三方防盗链直链？（本 Skill 默认如此，无需问，除非用户明确降低要求）

## 三、任务画像表（确认后生成）

把答案整理成一张表，作为方案的唯一事实源：

| 维度 | 内容 |
|---|---|
| 国家/路线 | 例：越南（胡志明→岘港）→ 老挝（万象→万荣→琅勃拉邦）→ 中国昆明 |
| 出发日期 / 天数 | 例：2026-11-07，15 天（含 2–3 天自由日） |
| 人数 | 2 人 |
| 预算 | 人均 ≤¥10,000（总 ≤¥20,000，含机票签证） |
| 住宿 | 70% 混住青旅 + 30% 特色酒店；位置优先市中心/海边 |
| 交通 | 直飞优先；体验中老铁路、跨境铁路；不坐长途大巴 |
| 导游 | 不需要全程导游；体验类活动当地参团 |
| 特色活动 | 烹饪课、AO Show、竹篮船、清晨布施、蓝湖树跳 |
| 饮食 | 当地特色美食，无忌口 |
| 文化 | 古城、寺庙、夜市、手工艺 |
| 商务考察 | 电子支付：越南 MoMo/VNPay、老挝 BCEL One；落地：公司注册+开户+支付接入费用 |
| 备注 | 节假日关注、无人机限制、报价表需要 |

## 四、画像 → 方案的关键决策规则

- 天数 <7 天：03 必体验只保留 TOP4；自由日最多 1 天
- 无考察需求：删除 04 商务考察专题，章节编号顺延
- 考察行业不同（如电商物流）：04 板块内容按行业重写，但结构（生态格局/落地路径/费用测算/核验状态表）不变
- 纯内陆国（如蒙古、老挝）：去掉"海边"类诉求与海滩板块内容，替换为该国特色自然景观（草原、戈壁、湖泊）
- 预算紧：航班选中转促销、住宿全青旅、体验只保留 2–3 个免费/低价项
- 多国路线：地图上按真实经纬度标注全部城市；跨境交通单独核实签证口岸政策
